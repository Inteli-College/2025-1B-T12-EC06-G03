## Visão Geral

&nbsp;&nbsp;&nbsp;&nbsp;O projeto Athena teve como objetivo desenvolver uma solução inovadora para a detecção e o monitoramento automatizado de fissuras em edificações, com foco em revestimentos de argamassa. A solução integra hardware (drone para captura de imagens) e software (plataforma web para análise e geração de relatórios), utilizando tecnologias como React, Java Spring Boot e OpenCV.

## Principais Resultados Alcançados

### Detecção e Classificação Automatizada de Fissuras
&nbsp;&nbsp;&nbsp;&nbsp;Foi desenvolvido um algoritmo para processamento de imagens na identificação e classificação de fissuras em fachadas de edifícios. O algoritmo utiliza técnicas de visão computacional e inteligência artificial, como o modelo YOLOv8 para detecção e uma CNN para classificação dos tipos de fissura (térmica e retração), alcançando uma acurácia de 95% na classificação.

### Interface Web Intuitiva
&nbsp;&nbsp;&nbsp;&nbsp;Criação de uma plataforma web que permite aos usuários cadastrar e gerenciar projetos de inspeção, enviar imagens, processar e classificar fissuras, gerar relatórios e exportar dados. Geração automatizada de relatórios técnicos em formato PDF.

### Interface Web Intuitiva
&nbsp;&nbsp;&nbsp;&nbsp;Foi criada uma plataforma web que permite aos usuários cadastrar e gerenciar projetos de inspeção, enviar imagens de fachadas, processar e classificar fissuras automaticamente, gerar relatórios detalhados e exportar dados em diversos formatos. A plataforma oferece uma experiência de usuário otimizada, com visualizações claras e interativas dos resultados da análise, facilitando a interpretação e o compartilhamento das informações.

### Controle Remoto de Drones
&nbsp;&nbsp;&nbsp;&nbsp;Foram implementadas funcionalidades para o controle remoto de drones, incluindo a visualização da câmera do drone em tempo real e o controle remoto através da interface web e do aplicativo.

### Arquitetura Escalável e Manutenível
&nbsp;&nbsp;&nbsp;&nbsp;Foi adotada uma arquitetura modular e escalável, com separação clara de responsabilidades entre as camadas (front-end, back-end, serviço de processamento), o que facilita a manutenção e a evolução do sistema.

## Perspectivas Futuras

- Integração com Realidade Virtual: Exploração de novas formas de interação com os dados através da realidade virtual.
- Aprimoramento dos Algoritmos de IA: Investimento em novos algoritmos de visão computacional para melhorar a precisão e a eficiência da detecção e classificação de fissuras.
- Expansão para Outras Aplicações: Adaptação da solução para outras áreas da engenharia civil, como a inspeção de pontes, túneis e outras estruturas.
