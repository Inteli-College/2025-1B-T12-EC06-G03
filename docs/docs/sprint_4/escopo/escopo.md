# Escopo da Sprint 4

## Introdução

A Sprint 4 do projeto Athena foi dedicada à validação da solução desenvolvida até o momento por meio de testes sistemáticos, além da expansão do escopo do projeto com a introdução de uma aplicação em realidade virtual (VR). Também foi realizada a primeira análise financeira do projeto, estimando sua viabilidade em escala. Esta sprint teve como prioridade a robustez técnica e a experiência do usuário, garantindo que o sistema fosse testado em múltiplas camadas: unitária, com desenvolvedores e com usuários reais.

Simultaneamente, iniciamos o desenvolvimento da aplicação de visualização em VR, que visa aumentar a imersão e facilitar a interpretação espacial das fissuras detectadas.

## Funcionalidades e Atividades Realizadas

### Requisitos Atualizados
- **Requisitos Funcionais**: Atualização com base nos feedbacks dos testes, incluindo novas funcionalidades desejadas e ajustes em funcionalidades existentes.
- **Requisitos Não Funcionais**: Revisão de parâmetros de desempenho, segurança e usabilidade, considerando os aprendizados das últimas sprints e testes realizados.

### Planejamento de Testes
- Elaboração de um plano de testes detalhado com cenários, critérios de aceitação, tipos de testes e métodos de coleta de feedback.

### Testes com os Usuários
- Aplicação de testes presenciais com usuários-alvo (como pesquisadores do IPT).
- Coleta de dados qualitativos e quantitativos sobre usabilidade, clareza das informações e fluidez do sistema.

### Testes com os Desenvolvedores
- Sessões de validação conduzidas internamente pela equipe de desenvolvimento para identificar bugs, falhas de integração e gargalos de performance.

### Testes Unitários dos Controllers
- Implementação de testes unitários para funções críticas da aplicação.
- Utilização de frameworks específicos para garantir cobertura mínima e evitar regressões.

### Análise Financeira do Projeto
- Primeira estimativa de custo do sistema completo, considerando infraestrutura, desenvolvimento, manutenção e operação.
- Cálculo de custo por análise realizada e projeção de ROI (retorno sobre investimento) com base em cenários simulados de uso no IPT.

### Aplicação em Realidade Virtual (VR)
- **Setup de Desenvolvimento VR**: Configuração do ambiente de desenvolvimento utilizando o framework A-Frame e integração com bibliotecas de WebXR.
- **Componentes A-Frame Customizados**: Criação de elementos personalizados para visualização 3D de fachadas e fissuras segmentadas.
- **Problemas de Integração VR**: Mapeamento de dificuldades encontradas na sincronização entre dados do sistema Athena e a visualização em VR.
- **API e Integração com Drone**: Início da estruturação de uma API que conectará os dados capturados pelo drone com a interface de realidade virtual.

## Conclusão

A Sprint 4 foi essencial para garantir a confiabilidade da aplicação Athena por meio de testes abrangentes e para explorar novas possibilidades de interação com os dados através da realidade virtual. Os aprendizados obtidos com os testes alimentarão as melhorias da Sprint 5, enquanto a base da aplicação VR representa um novo passo na inovação da interface e na apresentação dos resultados ao IPT.
